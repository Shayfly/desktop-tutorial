# חוזה המוצר החדש

Prompt -> ProductSpec -> Acceptance Contract -> Repository -> Sandbox -> Tests -> Repair -> PASS -> Deliver

## חיוב תיקונים
- Build crash / test failure: אחריות Omni.
- Requirement שהיה בחוזה ולא מולא: אחריות Omni.
- שינוי דעת המשתמש או feature חדש: Change Request, ניתן לחיוב credits.

## מודלים
ברירת מחדל: Local/Open-Weight OpenAI-compatible endpoint.
External fallback: כבוי כברירת מחדל.
ב-Zero-Cost Mode שום endpoint שמסומן external לא מורשה לפעול.
