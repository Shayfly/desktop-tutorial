# 148AI Brand System — V28 Launch Candidate

## Identity
**148AI** is the company-facing and product-facing master brand.

Primary line: **148AI — Build Anything.**

Working web home: `148ailabs.com`.

The older `Omni Creator` name remains only as an internal/backward-compatibility reference in some code/tests. New user-facing V28 surfaces use **148AI**.

## Distribution branding policy
| Plan | Visible 148AI mark | Removal | White-label | Provenance |
|---|---|---|---|---|
| Free | Required | No | No | Always |
| Basic | Required, subtle | No | No | Always |
| Pro | Optional | Yes | No | Always |
| Business | Optional | Yes | Yes | Always |
| Enterprise | Contract | Contract | Yes | Always/auditable |

The Branding Engine injects a `Built with 148AI` badge into generated HTML where the plan requires it and writes:
- `.148ai/brand-manifest.json`
- `.148ai/provenance.json`
- `public/148ai-badge.svg`

Raster image watermarking is implemented for plans/projects that require visible branding. Video/3D/audio receive branding/provenance instructions in their manifests until the real media/transcoding providers are connected.

## Brand integrity gate
The logo is founder-approved, but **formal trademark clearance is not complete**. Do not use ®. Trademark filing/clearance remains a founder/legal action before broad commercial expansion.
