# מה צריך להוכיח כדי לנהל שיחת שווי רצינית לפני הכנסות

אין קוד שמבטיח שווי חברה. שווי נקבע במשא ומתן לפי צוות, IP, מוצר, traction, שוק, תחרות וסיכון.

במקום "להבטיח מיליון דולר", Omni צריכה להגיע עם evidence package:

1. Demo חי: prompt → spec → generated repository → sandbox → tests → repair → PASS.
2. Benchmark: לפחות 30 תרחישים, עם success rate וזמן ממוצע.
3. Economics: עלות ממוצעת לכל build ולכל successful outcome.
4. Defensibility: orchestration, acceptance contract, repair data, model routing ו‑build telemetry.
5. Security: sandbox, tenant isolation, secrets, audit, rollback, backups.
6. Product: UX שניתן להפעיל בלי להיות מתכנת.
7. Distribution hypothesis: beta waitlist / design partners / first users.
8. Technical diligence package: source, tests, architecture, known blockers, reproducible setup.

אם הנתונים האלה חזקים, למשקיע יש בסיס אמיתי להעריך את החברה. בלי זה, מספר שווי הוא בעיקר סיפור.
