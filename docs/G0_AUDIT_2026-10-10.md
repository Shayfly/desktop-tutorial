## 1. Component map (what actually runs)
- **Web/API** (Vercel `148aiv28`, FastAPI `omni_prod/investor_app.py`): accounts, projects, discovery, plan/quote, approval → durable build request (Postgres outbox) → Redis queue.
- **Build worker** (Oracle host, `omni_prod/worker_tasks.py:execute_live_build_job`): contract binding → capability/infrastructure stages → `AutonomousProductEngine` (architect → generator → verify → repair loop) → release gates → **release policy** (new) → commit version (R2) → settlement → agent task graph.
- **Verification chain** (`investor_app._verification_executor`, inner → outer): remote sandbox (no network) ← consistency gate ← dependency allowlist ← preview smoke ← behavioural acceptance ← browser probe ← quality score ← model review.
- **Preview** (preview worker + router + Caddy): private by default, tokens, data volume per project.
- **State**: Neon Postgres (34 migrations), Upstash Redis, R2 (versions, round snapshots, backups).
- **Truth**: `AGENT_OS_REGISTRY.json`, `TRUTH_MATRIX.json`, matrices, evidence lock; all generated by `python -m omni_prod.agent_os.audit --write`.

## 2. Status vocabulary (now in code: `omni_prod/agent_os/contracts.py`)
NOT_IMPLEMENTED · IMPLEMENTED · UNIT_TESTED · INTEGRATION_TESTED · REAL_SERVER_VERIFIED · LIVE · BLOCKED.
**Correction:** what was reported as "LIVE" until now was verified on the pre-staging server; it is now REAL_SERVER_VERIFIED. LIVE requires production evidence; **0 capabilities are LIVE** (no production exists). A code change to an implementation file makes its evidence stale automatically (digest lock).

Inflation removed by this audit:
- Skills whose only "implementation" is an instruction to the model (`skills_runtime`) are capped at IMPLEMENTED (e.g. `contrast_test`, `responsive_layout`, `rtl_design`): no platform check verifies the result.
- `signup`/`login`/session/password skills of the *generated-app* auth agent were backed by evidence from **148AI's own** accounts → set NOT_IMPLEMENTED for generated apps; platform accounts are a separate truth-matrix row.
- Generated-app *integration* skills were backed by the platform's model-provider probe/429 handling → NOT_IMPLEMENTED for generated apps.
- `qa_agent` (running tests written by the coding agent) no longer counts as verifying the coding/repair agent; only the release policy (platform-owned) or a code review may.
