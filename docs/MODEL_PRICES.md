## הנחת "בנייה בינונית" (הערכה)

450K טוקני input, מתוכם 70% (315K) נקראים מה-cache, ועוד 150K טוקני output:

`עלות = (135K × input + 315K × cache + 150K × output) / 1M`

- מודל בלי מחיר cache: כל 450K מחושבים לפי `input`.
- **cache write לא נכלל.** Venice מחייב עליו בחלק מהמודלים (Claude, ‏GPT-5.6 ומעלה, ‏Qwen 3.6+, ‏Gemini 3.1 Pro/3.5 Flash). ההשפעה: 135K × מחיר cache write, וזה מגדיל את העלות. **התוצאות למטה הן חסם תחתון עבור המודלים האלה.**
- **מחירים מדורגים** (`>100K`/`>200K`/`>256K`/`>272K`) תלויים בגודל ה-context של קריאה בודדת, לא בסך הבנייה. ההנחה כאן היא שכל קריאה מתחת לסף. אם קריאות חוצות את הסף, העלות שלהן עולה. היחס משתנה בין מודלים (input / cache / output):

  - `qwen-3-7-plus` (>256K): פי 3
  - `qwen-3-6-plus` (>256K): input פי 4, ‏output פי 2
  - Grok (>200K): פי 2
  - GPT-5.4 ומעלה (>272K): input/cache פי 2, ‏output פי 1.5
  - `gemini-3-1-pro-preview` (>200K): input פי 2, ‏output פי 1.5
  (תוקן אחרי ביקורת Codex. הנוסח הקודם, "בערך פי 2", המעיט בהערכה.)
- 450K/150K הם הנחת עבודה שנמסרה ב-2026-10-19, **לא מדידה**. בקוד אין עדיין מדידה של טוקנים לבנייה אמיתית.
